# 运费大师

一个免安装的 Electron 桌面应用，用于快速计算美国、欧洲、加拿大、英国、澳大利亚的海运运费。内置 SQLite（sql.js）数据库，单价与附加费规则都可在软件内修改并自动保存。

## 功能

- 支持一票多箱：逐箱填写长/宽/高/实重，每箱单独计算计费重与附加费，自动汇总总运费，并给出每箱明细。
- 箱规最多 10 个，默认展示 1 个；提供「清空箱规」与「一键清空（箱规 + 目的地）」。
- 5 个目的地：美国（按邮编首字符分区）、欧洲（按国家）、加拿大、英国、澳大利亚。
- 计费重 = max(起重, ceil(长 × 宽 × 高 ÷ 体积重系数))；**起重取报价表第一栏**（默认 10KG，改表头即改起重）。
- 附加费按目的地独立配置：**两级条件字段** + **区间下限（≥）/上限（<）** + 金额 全部可改，可停用、可新增、可删除。条件字段分两级：

  | 主字段（条件字段） | 次级字段 |
  | --- | --- |
  | 边长 | 最长边 / 次长边 / 最短边 |
  | 重量 | 计费重（材积重）/ 实重 |
  | 围长 | —（无次级，直接判断围长） |
  | 体积 | —（无次级，直接判断体积） |

  库里存的仍是次级字段本身（如 `longest`、`charged_weight`），旧数据无需迁移。
- **规则组组合单独配置**：规则列表下方有独立的「规则组组合」区。每条规则都有 `#序号`，每个组合一行，行内用**复选框**勾出该组合包含哪些规则，再选该组合的行为；同一规则只能勾在一个组合里（勾到新组合会自动从旧组合移走）。
- 价格管理按国家分子页，每个国家一页，同时包含**起算重量设置**、单价表与附加费规则。
- **起算重量（最低计费重）每个国家单独设置**：一箱起算多少 KG、多箱时每个箱起算多少 KG；填 0 表示不设保底。
- 可恢复默认数据（价格与规则一起恢复出厂值）。
- **配置导出 / 导入**：一键把所有配置（体积重系数 + 五个目的地的阶梯、地区行、单价、附加费规则、起算重量）导出成 JSON 文件，换机器或备份时再导入即可。
- **批量导入箱规**：直接粘贴「重量32.60kg 尺寸：69*67*59」这类文本，自动识别多行并填写到箱规表里。

## 计费规则摘要

> 下面所有数值都是**出厂默认值**，均可在「价格管理」对应国家的页面里修改，修改后即时生效。

### 通用

1. 围长 =（最短边 + 次短边）× 2 + 最长边
2. 体积重 = ceil(长 × 宽 × 高 ÷ 体积重系数)，默认系数 6000
3. **每箱单独计算**：计费重 = max(起算重量, 体积重)
   - 起算重量按目的地在「价格管理 → 起算重量」里设置：**只填 1 个箱**时用「一箱起算」，**填 2 个及以上箱**时每个箱各按「多箱起算（每个箱）」；填 0 表示不保底
   - 五个目的地默认均为 10KG
4. 每箱按自己的计费重所在阶梯（如 10KG+ / 21KG+ / 71KG+ / 101KG+）确定单价，基础运费 = 该箱计费重 × 单价，最后各箱汇总

### 美国（叠加模式，阈值一律取「大于等于」）

| 规则组 | 条件 | 附加费 |
| --- | --- | --- |
| 实重 | 实重 ≥ 22.5KG | +120 |
| 围长 | 围长 ≥ 265 | +120 |
| 单边 | 最长边 ≥ 120CM 或次长边 ≥ 75CM（组内满足其一，只收一次） | +120 |
| 超大件 | 围长 ≥ 330 或三边相乘 ≥ 283168 或实重 ≥ 50KG（满足其一） | +500 |

- 前 3 组可叠加；命中「超大件」时只收 500，前 3 组不再计入。

### 欧洲（不叠加，取金额最高）

| 条件 | 附加费 |
| --- | --- |
| 围长 ≥ 330 | +350 |
| 围长 ≥ 300 | +300 |
| 实重 ≥ 30KG | +300 |

### 加拿大（叠加模式；命中超大件只收 700）

| 规则组 | 条件 | 附加费 |
| --- | --- | --- |
| ①实重 | 实重 ≥ 22KG | +130 |
| ②单边 | 最长边 ≥ 121CM 或次长边 ≥ 75CM | +130 |
| ③围长 | 最长边 +（宽+高）×2 ≥ 265CM | +130 |
| ④超大件 | 围长 ≥ 320CM 或 实重 ≥ 40KG（满足其一） | +700（不再叠加①②③） |
| ⑤不收货 | 实重 ≥ 68KG 或 最长边 ≥ 151CM 或 围长 ≥ 400CM（满足其一） | 不收货，计算时直接报错提示 |

### 英国（叠加模式；②与③互不叠加，①可与②/③叠加）

| 规则组 | 条件 | 附加费 |
| --- | --- | --- |
| ①实重30-40 | 30KG ≤ 实重 < 40KG | +330 |
| ②③尺寸 | 100 ≤ 最长边 < 150，或 70 ≤ 次长边 < 100，或 60 ≤ 最短边 < 100，或 300 ≤ 围长 < 400（满足其一，只收一次） | +300 |

- ①与②③同时命中时叠加（如 630）；②与③同时命中不叠加（300）。
- 说明：报价里的「长/宽/高」按最长边/次长边/最短边解释；③的「长+2×(宽+高)」即围长。

### 澳大利亚（叠加模式；按计费重收附加费）

| 规则组 | 条件 | 附加费 |
| --- | --- | --- |
| 计费重≥30 | 30KG ≤ 计费重 < 35KG | +100 |
| 计费重≥35 | 35KG ≤ 计费重 < 80KG | +300 |
| 计费重≥80 | 计费重 ≥ 80KG | +300 |
| 单边120-199 | 120CM ≤ 最长边 < 200CM | +100 |
| 单边200-299 | 200CM ≤ 最长边 < 300CM | +200 |
| 木托盘提醒 | 实重 ≥ 30KG | 不收费，结果里提示「需要打木托盘」 |

### 加拿大 / 英国 / 澳大利亚的单价

- 三个目的地的**单价仍为占位值 0**，请先在「价格管理」里填写实际报价。
- 阶梯默认与欧洲一致（10KG+ / 21KG+ / 101KG+），表头可直接改。

### 附加费行为（6 种，可逐条规则配置）

在「附加费规则」表格下方的「规则组组合」区，勾选要放进同一个组合的规则，并为该组合选择其中一种行为（同一组合内所有规则共用同一行为，改一次整组生效）：

| 行为 | 计算方式 |
| --- | --- |
| 叠加 | 同组（满足任一条件取组内最高）与其他叠加组求和 |
| 不叠加 | 同组去重后累加，**不会被「不叠加取最高」替换** |
| 不叠加取最高 | 命中任一条时**只收这一类的最高金额**，叠加 / 不叠加 组全部不计；卡派 / 提醒 / 拒收仍照常 |
| 卡派 | 卡车派送等固定费用，**单独累加**，不受「不叠加取最高」影响 |
| 提醒 | 不收钱，结果里给出提示 |
| 拒收 | 命中即不收货，计算时直接报错 |

**组合示例**：5 条规则覆盖一个国家 — ① 叠加 100，② 叠加 200，③ 不叠加 50，④ 不叠加取最高 500，⑤ 卡派 80
- ①+② 命中 → 300
- ①+②+③ 命中 → 350
- ①+②+③+④ 命中 → 只收 ④ 500，①/②/③ 不计 → 500
- 任意组合 + ⑤ → 单独 +80

## 使用方式

### 批量导入箱规

在「运费计算」页的箱规表格下方点「批量导入箱规」，粘贴文本后点「解析并填入」或「解析并计算」：

```
重量32.60kg 尺寸：69*67*59
重量21.50kg 尺寸：96*73*40
```

识别规则（宽松，一行一箱）：

- **重量**：优先取带单位的数字（`32.60kg` / `32.60千克` / `32.60公斤`），否则取「重量 / 实重 / weight」后面的数字
- **尺寸**：三个数字用 `x` `X` `×` `*` `·` `/` `\` 分隔（`69*67*59`、`69x67x59`、`69×67×59` 都行）
- 重量和尺寸**写在同一行或分两行都支持**（分两行时上一行的重量会配给下一行的尺寸）
- 只识别到尺寸却找不到重量时，会提示「第 N 行：识别到尺寸 …，但没找到重量」

### 导出 / 导入配置

在「价格管理」页最下方：

- **导出配置**：弹保存对话框，把当前全部配置写成 JSON（含体积重系数、五个目的地的阶梯 / 地区行 / 单价 / 附加费规则 / 起算重量）
- **导入配置**：选一个之前导出的 JSON，整份覆盖当前配置（会二次确认）

导出的 JSON 结构：

```json
{
  "format": "freight-master-config",
  "version": 1,
  "exportedAt": "2026-10-20T...",
  "volDivisor": 6000,
  "groups": [
    {
      "key": "us",
      "name": "美国",
      "mode": "zip",
      "minWeightSingle": 10,
      "minWeightPerBox": 10,
      "tiers": [{ "id": 1, "min_weight": 10, "label": "10KG+" }],
      "rows": [{ "id": 1, "name": "美西（邮编8,9开头）", "matchKey": "8,9", "prices": { "1": 16.7 } }],
      "rules": [{ "rule_group": "实重", "field": "weight", "threshold": 22.5, "threshold_max": null, "amount": 120, "combine_mode": "add", "enabled": 1 }]
    }
  ]
}
```

导入时会先整份校验（格式标记、是否缺少阶梯、目的地是否合法/重复），全部通过才写入数据库，避免写一半失败留下脏数据。

### 开发运行

```bash
cd freight-master
npm install
npm start          # 桌面端（Electron）
```

### 局域网开发服务（让同事用浏览器直接访问）

```bash
npm run serve                       # 默认监听 0.0.0.0:5173
node server.mjs --port 8080         # 换端口
node server.mjs --db ./other.db     # 换数据库文件
```

启动后终端会打印内网地址（如 `http://192.168.1.23:5173`），同事用浏览器打开即可，页面与桌面端完全一致（同一份 `renderer.js` + `core.js`）。

注意：

- **仅限局域网开发联调**：服务没有登录鉴权，不要直接暴露到公网
- 同事打不开时先排查：Windows 防火墙是否放行该端口、公司 Wi-Fi 是否开了 AP 隔离（可让同事先 `ping` 你的内网 IP）
- 数据库是单文件写盘，**多人同时改价格会互相覆盖**（最后写入胜出）；正式多人使用需要加锁或改成服务端单一写入
- 浏览器模式下「导出配置」变成直接下载 JSON 文件，「导入配置」变成选择本地 JSON 文件（没有原生对话框）

### 打包成绿色版

```bash
npm run build
```

打包产物在 `dist-pack\运费大师-win32-x64\`，整个文件夹拷到任何 Windows 电脑后双击 `运费大师.exe` 即可运行，无需安装、无需解压。

如需分发，把这个文件夹压缩成 zip 发给对方即可。

## 数据文件

首次运行会在程序目录生成 `freight-master.db`，即为 SQLite 数据库文件：

- 桌面端开发模式：项目根目录下的 `freight-master.db`
- 打包后：`运费大师.exe` 同级的 `freight-master.db`
- 局域网服务：默认同样是项目根目录，可用 `--db` 指定别的位置

价格与规则修改都会自动保存到该文件，复制该文件即可迁移数据。数据库包含 5 张表：

| 表名 | 内容 |
| --- | --- |
| `rate_tiers` | 各目的地的重量阶梯（第一栏 = 起重） |
| `rate_rows` | 各目的地的地区/国家行（美国附邮编前缀） |
| `rate_values` | 行 × 阶梯 的单价 |
| `surcharge_rules` | 各目的地的附加费规则 |
| `settings` | 体积重系数、附加费叠加方式等 |

旧版本（us_rates / eu_rates / us_surcharge_config / eu_surcharge_rules）升级时会自动迁移到新表，已有的价格数据不会丢失。

## 技术栈

- Electron 33
- @electron/packager 20（Electron 官方打包器）
- sql.js（SQLite 纯 JS 实现，无需额外编译）
- 局域网开发服务：`node:http` 零依赖实现
- 原生 HTML / CSS / JavaScript

## 代码结构

| 文件 | 作用 |
| --- | --- |
| `core.js` | 数据库、运费计算、配置导入导出（纯 Node，无 Electron 依赖） |
| `main.js` | Electron 桌面端入口：窗口 + IPC 桥接 |
| `preload.js` | 桌面端把 IPC 暴露成 `window.freightApi` |
| `server.mjs` | 局域网开发服务：静态托管 + `/api/*` 路由 |
| `web-api.js` | 浏览器端用 fetch 实现同名 `window.freightApi`（Electron 下自动跳过） |
| `renderer.js` / `index.html` / `styles.css` | 页面，桌面端与浏览器端共用 |
