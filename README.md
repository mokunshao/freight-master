# 运费大师

一个免安装的 Electron 桌面应用，用于快速计算美国、欧洲、加拿大、英国、澳大利亚的海运运费。内置 SQLite（sql.js）数据库，单价与附加费规则都可在软件内修改并自动保存。

## 功能

- 支持一票多箱：逐箱填写长/宽/高/实重，每箱单独计算体积重与附加费；**基础运费按整票合计计费重合并计算**，自动汇总总运费，并给出每箱明细。
- 箱规最多 10 个，默认展示 1 个；提供「清空箱规」与「一键清空（箱规 + 目的地）」。
- 5 个目的地：美国（按邮编首字符分区）、欧洲（按国家）、加拿大、英国、澳大利亚。
- 计费重 = max(起重, ceil(长 × 宽 × 高 ÷ 体积重系数))；**起重取报价表第一栏**（默认 10KG，改表头即改起重）。
- 附加费按目的地独立配置：条件字段（实重/计费重/围长/最长边/次长边/最短边/体积）+ **区间下限（≥）/上限（<）** + 金额全部可改，支持「可叠加 / 超大件（命中不叠加）/ 达到即不收货 / 仅提醒」四种类型，可停用、可新增、可删除。
- 价格管理按国家分子页，每个国家一页，同时包含单价表与附加费规则。
- 可恢复默认数据（价格与规则一起恢复出厂值）。

## 计费规则摘要

> 下面所有数值都是**出厂默认值**，均可在「价格管理」对应国家的页面里修改，修改后即时生效。

### 通用

1. 围长 =（最短边 + 次短边）× 2 + 最长边
2. 每箱体积重 = ceil(长 × 宽 × 高 ÷ 体积重系数)，默认系数 6000
3. **基础运费整票合并计算**：整票计费重 = max(起重, 各箱体积重之和)，起重（报价表第一栏，默认 10KG）整票只算一次
4. 用整票计费重所在阶梯（10KG+ / 21KG+ / 71KG+ / 101KG+）确定单价，基础运费 = 整票计费重 × 单价（只算一次）
5. 附加费仍**按单箱**判定后相加（澳大利亚的「单件计费重」取该箱自身的计费重）

### 美国（叠加模式，阈值一律取「大于等于」）

| 规则组 | 条件 | 附加费 |
| --- | --- | --- |
| 实重 | 实重 ≥ 22.5KG | +120 |
| 围长 | 围长 ≥ 265 | +120 |
| 单边 | 最长边 ≥ 120CM 或次长边 ≥ 75CM（组内满足其一，只收一次） | +120 |
| 超大件 | 围长 ≥ 330 或三边相乘 ≥ 283168 或实重 ≥ 50KG（满足其一） | +500 |

- 前 3 组可叠加；命中「超大件」时只收 500，前 3 组不再计入。

### 欧洲（不叠加，取金额最高）

| 条件 | 附加费 |
| --- | --- |
| 围长 ≥ 330 | +350 |
| 围长 ≥ 300 | +300 |
| 实重 ≥ 30KG | +300 |

### 加拿大（叠加模式；命中超大件只收 700）

| 规则组 | 条件 | 附加费 |
| --- | --- | --- |
| ①实重 | 实重 ≥ 22KG | +130 |
| ②单边 | 最长边 ≥ 121CM 或次长边 ≥ 75CM | +130 |
| ③围长 | 最长边 +（宽+高）×2 ≥ 265CM | +130 |
| ④超大件 | 围长 ≥ 320CM 或 实重 ≥ 40KG（满足其一） | +700（不再叠加①②③） |
| ⑤不收货 | 实重 ≥ 68KG 或 最长边 ≥ 151CM 或 围长 ≥ 400CM（满足其一） | 不收货，计算时直接报错提示 |

### 英国（叠加模式；②与③互不叠加，①可与②/③叠加）

| 规则组 | 条件 | 附加费 |
| --- | --- | --- |
| ①实重30-40 | 30KG ≤ 实重 < 40KG | +330 |
| ②③尺寸 | 100 ≤ 最长边 < 150，或 70 ≤ 次长边 < 100，或 60 ≤ 最短边 < 100，或 300 ≤ 围长 < 400（满足其一，只收一次） | +300 |

- ①与②③同时命中时叠加（如 630）；②与③同时命中不叠加（300）。
- 说明：报价里的「长/宽/高」按最长边/次长边/最短边解释；③的「长+2×(宽+高)」即围长。

### 澳大利亚（叠加模式；按计费重收附加费）

| 规则组 | 条件 | 附加费 |
| --- | --- | --- |
| 计费重≥30 | 30KG ≤ 计费重 < 35KG | +100 |
| 计费重≥35 | 35KG ≤ 计费重 < 80KG | +300 |
| 计费重≥80 | 计费重 ≥ 80KG | +300 |
| 单边120-199 | 120CM ≤ 最长边 < 200CM | +100 |
| 单边200-299 | 200CM ≤ 最长边 < 300CM | +200 |
| 木托盘提醒 | 实重 ≥ 30KG | 不收费，结果里提示「需要打木托盘」 |

### 加拿大 / 英国 / 澳大利亚的单价

- 三个目的地的**单价仍为占位值 0**，请先在「价格管理」里填写实际报价。
- 阶梯默认与欧洲一致（10KG+ / 21KG+ / 101KG+），表头可直接改。

## 使用方式

### 开发运行

```bash
cd freight-master
npm install
npm start
```

### 打包成绿色版

```bash
npm run build
```

打包产物在 `dist-pack\运费大师-win32-x64\`，整个文件夹拷到任何 Windows 电脑后双击 `运费大师.exe` 即可运行，无需安装、无需解压。

如需分发，把这个文件夹压缩成 zip 发给对方即可。

## 数据文件

首次运行会在程序目录生成 `freight-master.db`，即为 SQLite 数据库文件：

- 开发模式：项目根目录下的 `freight-master.db`
- 打包后：`运费大师.exe` 同级的 `freight-master.db`

价格与规则修改都会自动保存到该文件，复制该文件即可迁移数据。数据库包含 5 张表：

| 表名 | 内容 |
| --- | --- |
| `rate_tiers` | 各目的地的重量阶梯（第一栏 = 起重） |
| `rate_rows` | 各目的地的地区/国家行（美国附邮编前缀） |
| `rate_values` | 行 × 阶梯 的单价 |
| `surcharge_rules` | 各目的地的附加费规则 |
| `settings` | 体积重系数、附加费叠加方式等 |

旧版本（us_rates / eu_rates / us_surcharge_config / eu_surcharge_rules）升级时会自动迁移到新表，已有的价格数据不会丢失。
