# 运费大师

一个免安装的 Electron 桌面应用，用于快速计算美国、欧洲海运运费。内置 SQLite（sql.js）数据库，价格数据可随时在软件内修改并自动保存。

## 功能

- 支持一票多箱：逐箱填写长/宽/高/实重，每箱单独计算计费重与附加费，自动汇总总运费，并给出每箱明细。
- 美国运费计算：按邮编首字符分区（美西 8/9、美中 4/5/6/7、美东 0/1/2/3），自动匹配计费重阶梯单价。
- 欧洲运费计算：按国家选择，自动匹配计费重阶梯单价。
- 自动计算围长、计费重（体积 ÷ 体积重系数，向上取整）。
- 自动判断并叠加/选取附加费。
- 价格管理页面：可修改各分区/国家不同重量阶梯的单价，修改后自动持久化到本地数据库文件。
- 计费与附加费规则页面：体积重系数、美国附加费阈值与金额、欧洲附加费规则（可增删改、可停用）全部可调。
- 可恢复默认数据（价格与规则一起恢复出厂值）。

## 计费规则摘要

> 下面所有数值都是**出厂默认值**，均可在「计费与附加费规则」页面里修改，修改后实时生效。

### 美国

1. 围长 =（最短边 + 次短边）× 2 + 最长边
2. 计费重 = ceil(长 × 宽 × 高 / 体积重系数)，默认系数 6000
3. 单价按邮编分区 + 计费重所在阶梯（10KG+ / 21KG+ / 71KG+ / 101KG+）确定
4. 附加费（以上均为默认值，阈值一律取「大于等于」）：
   - 实重 ≥ 22.5KG：+120
   - 围长 ≥ 265：+120
   - 最长边 ≥ 120CM 或次长边 ≥ 75CM：+120
   - 以上 3 项可叠加
   - 超大件（围长 ≥ 330 或 三边相乘 ≥ 283168 或 实重 ≥ 50KG，满足其一即可）：+500，命中超大件时不再叠加前 3 项

### 欧洲

1. 围长与计费重计算同上
2. 单价按国家 + 计费重阶梯（10KG+ / 21KG+ / 101KG+）确定
3. 附加费（不叠加，取最高）：
   - 围长 ≥ 330：+350
   - 围长 ≥ 300：+300
   - 实重 ≥ 30KG：+300

## 使用方式

### 开发运行

```bash
cd freight-master
npm install
npm start
```

### 打包成绿色版

```bash
npm run build
```

打包产物在 `dist-pack\运费大师-win32-x64\`，整个文件夹拷到任何 Windows 电脑后双击 `运费大师.exe` 即可运行，无需安装、无需解压。

如需分发，把这个文件夹压缩成 zip 发给对方即可。

## 数据文件

首次运行会在程序目录生成 `freight-master.db`，即为 SQLite 数据库文件：

- 开发模式：项目根目录下的 `freight-master.db`
- 打包后：`运费大师.exe` 同级的 `freight-master.db`

价格与规则修改都会自动保存到该文件，复制该文件即可迁移数据。数据库包含 5 张表：

| 表名 | 内容 |
| --- | --- |
| `us_rates` | 美国分区价格 |
| `eu_rates` | 欧洲国家价格 |
| `settings` | 通用参数（体积重系数） |
| `us_surcharge_config` | 美国附加费阈值与金额 |
| `eu_surcharge_rules` | 欧洲附加费规则（可增删改） |

旧版本升级时会自动补齐新表，已有的价格数据不会丢失。
