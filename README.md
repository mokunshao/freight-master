# 运费大师

一个免安装的 Electron 桌面应用，用于快速计算美国、欧洲海运运费。内置 SQLite（sql.js）数据库，价格数据可随时在软件内修改并自动保存。

## 功能

- 美国运费计算：按邮编首字符分区（美西 8/9、美中 4/5/6/7、美东 0/1/2/3），自动匹配计费重阶梯单价。
- 欧洲运费计算：按国家选择，自动匹配计费重阶梯单价。
- 自动计算围长、计费重（体积/6000 向上取整）。
- 自动判断并叠加/选取附加费。
- 价格管理页面：可修改各分区/国家不同重量阶梯的单价，修改后自动持久化到本地数据库文件。
- 可恢复默认价格数据。

## 计费规则摘要

### 美国

1. 围长 =（最短边 + 次短边）× 2 + 最长边
2. 计费重 = ceil(长 × 宽 × 高 / 6000)
3. 单价按邮编分区 + 计费重所在阶梯（10KG+ / 21KG+ / 71KG+ / 101KG+）确定
4. 附加费：
   - 实重 > 22.5KG：+120
   - 围长 > 265：+120
   - 最长边 > 120CM 或次长边 > 75CM：+120（可叠加）
   - 超大件（围长 > 330 或 体积 ≥ 283168 或实重 > 50KG）：+500，且不再叠加前 3 项

### 欧洲

1. 围长与计费重计算同上
2. 单价按国家 + 计费重阶梯（10KG+ / 21KG+ / 101KG+）确定
3. 附加费（不叠加，取最高）：
   - 围长 ≥ 330：+350
   - 围长 ≥ 300：+300
   - 实重 ≥ 30KG：+300

## 使用方式

### 开发运行

```bash
cd freight-master
npm install
npm start
```

### 打包成绿色版

```bash
npm run build
```

打包产物在 `dist-pack\运费大师-win32-x64\`，整个文件夹拷到任何 Windows 电脑后双击 `运费大师.exe` 即可运行，无需安装、无需解压。

如需分发，把这个文件夹压缩成 zip 发给对方即可。

## 数据文件

首次运行会在程序目录生成 `freight-master.db`，即为 SQLite 数据库文件：

- 开发模式：项目根目录下的 `freight-master.db`
- 打包后：`运费大师.exe` 同级的 `freight-master.db`

价格修改会自动保存到该文件，复制该文件即可迁移数据。
